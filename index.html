Self-diagnostic

Everything visible from this tab, right now.

No data leaves this page except two lookups you can see below (your public IP and its rough location, fetched from ipapi.co so the network panel has something to show). Nothing is stored or sent anywhere else — reload the page and it's gone.

Some readings only appear after you grant permission (location, camera/mic labels, motion) — those live in Sensors & Permissions and need a secure context (HTTPS, or localhost). Everything in Session Behavior and Silent Signals below needs no prompt at all — it's the same category of passive tracking session-replay tools like FullStory rely on, and it starts collecting the instant this page loads.

Built for personal use — open the page source any time to see exactly what's being read. Host it over HTTPS (e.g. GitHub Pages, or a Tailscale/Caddy box on your LAN) to unlock the permission-gated panels on phones too.
